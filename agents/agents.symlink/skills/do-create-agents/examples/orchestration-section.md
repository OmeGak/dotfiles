# Orchestration section template

Paste into the project's `CLAUDE.md` (create the file if missing). Keep it under 150 words. The global orchestrator policy in `~/.claude/CLAUDE.md` says *how* the main session routes; this section says *what it routes over* for this project. Fill every `<blank>`; delete lines that do not apply.

````markdown
## Orchestration

Dates every brief serves:
- <milestone>: <date>

Facts never re-derived (read the file, don't guess):
- the roster and each seat's scope: .claude/agents/README.md
- <the project's plan, backlog, or status file, or the issue tracker command>
- <where finished work lands: drafts/, docs/research/, data/>

Never, in this project:
- <outward-facing or irreversible actions specific here, e.g. no `gh` writes, no submitting an application>
- <conversations the owner has in the main session and never delegates>

Every run ends with a briefing: moved / blocked / needs a call, one line per item, each blocker naming who clears it.
````
